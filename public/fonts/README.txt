Self-hosted subsets (printable ASCII, U+0020-007E) of three Google Fonts, all under the SIL Open Font License 1.1
(https://openfontlicense.org). Downloaded from the Google Fonts API (text= subsetting) as variable woff2 files.
The site copy is plain ASCII; any other character falls back to the local fonts.

- fraunces-latin.woff2, fraunces-italic-latin.woff2: Fraunces, Copyright The Fraunces Project Authors
- dm-sans-latin.woff2: DM Sans, Copyright The DM Sans Project Authors
- caveat-latin.woff2: Caveat, Copyright The Caveat Project Authors
